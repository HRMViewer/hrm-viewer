1Getting started

  1. Download HRM-Viewer-<version>-full.zip from github.com/HRMViewer/hrm-viewer/releases and unzip the HRM Viewer folder somewhere permanent, for example Documents\HRM Viewer.
  2. Double-click HRM Viewer.exe. It opens in its own window. The first time, it offers to add shortcuts to your desktop and Start menu.
    • Nothing else needs installing: everything it uses, including its own Python, is in the folder.
    • If Windows says “Windows protected your PC”, click More info → Run anyway.
  3. Click Load new database (top right), paste the path to your game's database.db (or choose the file) and press Load.
Tip: you can also drag database.db onto HRM Viewer.exe to open the viewer and load it in one go.

On a Mac

  1. Download HRM-Viewer-<version>-mac.zip, double-click it to unzip, and drag HRM Viewer into your Applications folder. It works on Apple Silicon and Intel Macs with macOS 11 or later.
  2. Open it. The first time, the Mac says it “could not verify” HRM Viewer, because the app isn't signed with a paid Apple developer account. Click Done, open System Settings → Privacy & Security, scroll down and click Open Anyway next to HRM Viewer, then confirm. You only do this once.
  3. Load your database as above. Your data is kept in Library/Application Support/HRM Viewer in your home folder, so it stays when you replace the app with a newer one. Files you download (CSV, chart pictures) go to your Downloads folder.

On Linux and Steam Deck (desktop mode)

  1. Download HRM-Viewer-<version>-linux.tar.gz and unpack it in your home folder.
  2. Open HRM Viewer in that folder. The first time, it offers to add itself to your applications menu (also in Settings → Versions & changes → Desktop app).
  3. It opens in its own window when WebKitGTK 4.1 or 4.0 is installed (most desktops have one). If the window can't start, it tries again with safe graphics settings and remembers what worked. Without WebKitGTK it opens in your browser, and Settings says why; stop it there with Stop the viewer.

3Loading your saves

Load a newer save

Quickest: save in the game, then click Update data at the top, beside the search box. The viewer loads the newest save from the same database.db straight away and shows the new data; if the save hasn't changed it says it's already up to date. (On a narrow window it's the ↻ button.)

Or click Load new database and press Load (the path is remembered). Each load builds on what's stored:

  • Records in the new file replace older versions; history the game has since deleted (old results, finances, news…) is kept.
  • If a file is older than what's stored, or from a different career, the viewer asks first.

Following the game as you play

Settings → Databases → Load new saves automatically is on to begin with: leave the viewer open, and every time you save in the game it loads the new file by itself (switch it off there if you'd rather load saves yourself). ● Auto at the top shows it's on. You can change which file it follows there too (Save file to follow).

Several databases

Settings → Databases lets you keep different saves apart, switch between them, rename or delete them, and bring in data from another HRM Viewer folder. Click the database name at the top right to get there quickly.

Each database follows one player. If a save's player is different from the database's (for example your heir has taken over), or the file is from a different save, the viewer asks before loading it, even during automatic updates: Same world keeps using this database, or make a new database for the new player. The Databases list shows each database's player and any players it followed before.

Compact stored data

The stored copy keeps everything the game has ever had, so it grows. Settings → Databases → Stored data → Compact stored data (off to begin with) makes it smaller without losing anything you can see in the viewer: each time a save is loaded it drops the game's rating history and race replays, its Yearly Summary story entries and their hidden data, and other people's horses' raw race positions once their sectional times are worked out (the sectionals are kept). It also rebuilds the biggest tables without a duplicate copy of their ID index. Compact now does it straight away. What it drops can't come back, and loading takes a little longer while it's on.

On Windows, Compress on disk (off to begin with) keeps the stored data compressed on your drive, the same as ticking Compress contents to save disk space on the folder: it takes roughly half the space, nothing in it is removed, and pages read it as normal. Each load compresses the new copy before it's used, which adds about 10 seconds per GB; you can keep using the viewer meanwhile. It works on NTFS drives (most Windows drives); Size shows the space the stored data takes on disk.

Under Status in the same place you can see when the last update ran and how long it took, with the time for each step, followed by the size of the save file it loaded and of the stored data it made.

4Horses

  • Pedigree — on a horse's Overview, three generations (sire and dam, grandparents, great-grandparents; blue edge for males, pink for females) with the race record of each parent and grandparent. Beside it: the sire's and dam's records and number of foals, the damsire, how many full siblings it has, and any ancestor that appears more than once within three generations. Full pedigree opens the Pedigree tab.
  • Owners — on a horse's Overview, taking half the line beside Physical and Connections: every stable that has owned it, oldest first, with the date it took over, what it paid and how — Bred (the first owner), Auction (with a link to the sale), Private sale or Free transfer (no money changed hands, such as a horse sent to the shelter). Now marks the current owner.
  • Training & plans — a tab on every horse, in four sections you can jump between from the menu at the top. Training: its daily programme, food and care, the effect of each on its stats and from its staff (green helps, red holds it back), and its shoes. Season & race plan: its yearly schedule (days of preparation and recovery) and the races its plan aims it at. Campaigns & qualifying: campaigns the game has suggested (Triple Crowns and the like) and the races it has qualified for. Rankings & syndicate: career earnings, earnings for its age, offspring earnings and pedigree, each as the game's top x%, and, when it has one, its syndicate: who manages it, the shares, price and fee, and every shareholder.
  • Compare — Compare… at the right of a horse's or person's tabs puts two side by side (search for the second); the better figure of each pair is in bold green.
  • Horse page — the horse's traits sit under its age, colour and breed at the top (point at one for what it means). The Overview opens with three same-size boxes on one line: Physical, Pedigree and Connections. Then the form guide (record by track, condition and distance), its last 5 starts and track records held. Then Charts: value over time, its starts each season split into wins, 2nds, 3rds and unplaced, and prize money by season side by side; the game's rating for each run; and its finishing positions. Then the game's rankings. Other tabs: Pedigree (the full family tree, as on the Pedigrees page but inside the horse page, so its tabs stay at the top, with its offspring underneath), Health (see below), News, Awards, Fans, sponsors & notes and Training & plans.
  • Health — a tab on every horse: whether it's healthy now, its condition, health risk (and the lowest it can go), weight, how many illnesses and injuries it has had and how many days they lasted. Anything it has now is shown in full: what it is, since when, how far it has recovered (or that it's chronic and stays), the usual recovery time, treatment, complications and how much of its ability it races with meanwhile. Then its condition over time, illnesses and injuries each year, and its full health history.
  • Races & trials — a tab on every horse. Its full race record with jockey, trainer, stable and gear (point at the gear letters for full names), time, odds, rating and prize. Then its timing trials: Trial sessions lists each day it was timed at a course (track and surface, jockey, its condition, the distances run, how many horses were timed, and its best and average place against them), and Trial times by distance puts its time at every distance side by side, session by session, with its place and how far behind the fastest, then its average, slowest and best time at each distance over every session; gold underlines its best. Every trial run lists each run on its own line: date, racecourse, track and surface, distance, time, average speed, place, gap to the fastest, jockey and condition. The game times each distance as its own run and keeps only the finishing time, so there are no split times for trials.
  • Horse awards — the Awards tab on a horse's page lists every season award and Group/Listed race win, with the jockey and the stable it raced for. Filter by season awards or race wins, wins only, year, or search.
  • Photos — on a horse's page click Add photos (or Gallery) to upload pictures (JPG, PNG, GIF or WebP; click to choose or drag them in). Under each photo, ★ Profile makes it the horse's profile picture (next to its name, and small in All horses and the Horse table) and ▭ Banner puts it across the top of the horse's hover card (no banner chosen = no picture on the hover card). Under Banner view you choose how it looks: drag the preview to pick which part shows, zoom, fill the banner or show the whole picture, short/medium/tall, and sharp pixels for pixel art. Add as many photos as you like; the row slides sideways (‹ › or scroll) when there are more than fit. Photos are kept with that database, on your computer.
  • Fans, sponsors & notes — a tab on every horse's page. Tiles show its fans, its world rank by fans (among living horses), its fan level, its sponsor now and everything sponsors have paid. Fan milestones is the ladder the save records for every horse: Fan website (top 100 by fans), Supporters' club (top 50), Fan club trips (top 20), Superfans (top 10) and No. 1, lit up to the best it has reached (for your own horses, with the date from your inbox); steps it has since dropped out of are marked Not any more with its rank now. Sponsors lists every sponsor it has had, with the monthly payment, win bonus, dates, wins and total paid; From your inbox (your horses) lists the fan and merchandise messages, with the fans and rank at the time and any money offered or asked for.
  • Tags — make your own tags in Settings → Tags: type a name, pick one of ten colours and click Create tag. Rename one by typing over it, click a colour to change it, or delete it (it comes off every horse; it asks first). Then tick them on a horse's Fans, sponsors & notes tab under Your tags: click one to put it on or take it off. Your tags show beside the horse's name on every tab and in All horses and the Horse table. Back up your notes and tags on the same page downloads everything as one file, and brings a backup back (added to what's there, or replacing it); it never doubles up a note you already have.
  • Notes — Your notes, on the right of a horse's Fans, sponsors & notes tab, is a log: write a note and press Enter to save it (Shift+Enter for a new line). Each note shows when you wrote it and the game date then, newest first; the list scrolls when it's longer than the box. Edit changes a note in place (Enter saves, Esc cancels) and Delete removes it after asking once. A note icon beside the horse's name in the lists shows the latest note when you point at it. Horses → Notes & tags lists every horse you've tagged or written about, with its latest note, and searches all your notes. Only you see notes and tags; they're kept with the database, so they stay when you load a newer save into it.
  • Automatic tags — outlined chips in All horses and the Horse table show what the save itself records: the best fan level the horse has reached (Fan website, Supporters' club, Fan club trips, Superfans, No. 1 by fans; dashed, with its rank now, if it isn't at that level any more, e.g. No. 1 by fans · now #2), Sponsored if it has a sponsor now, and Merch if you've been offered a merchandise deal for it. Point at one for details. The Any tags filter has them too (the Auto: options), alongside your own tags, Tagged by you and With your notes. The Horse table also has Fans, Fan level and Sponsor columns (sort by fans or by monthly sponsorship).
  • Family tree — four generations on the page; bigger trees (8, 12, 16 generations) as a list with copy buttons. Tick a name under Most influential ancestors to highlight it everywhere in the tree.
  • All horses — search, filter (Alive · Deceased · All, sex) and sort every horse.
  • Horse table — every horse with its key stats in one sortable table.
  • Top sires / Top dams / Broodmare sires — ranked by how their foals have done; filter by foal age, sex and minimum runners. Horses in stables you own are marked Yours; Your stables only shows just those.
  • Your stables stand out — in every table that isn't about stables (horse lists, race results and entries, people, race records and more), rows for horses and people in stables you own are gold with a bar down the left; a key under the table says so. Stables you only manage or hold shares in aren't highlighted, nor is a table where every row is yours.

Horse lists. All horses and the Horse table have a # column with each horse's rank in the column you sort by, a Role filter (Racing: ran in the last 12 months; Breeding: at stud, leased, in foal or had a foal in the last two years; Retired: neither; Not raced yet: no starts and under 5; horses you've pinned to a list in the game go there) and a Sires & mares filter (stallions that have sired foals or stand at stud; mares that have had foals or are in foal).

5Racing & racecourses

Concepts. Racing → Concepts lists every race series (Triple Crowns, Triple Tiaras, the Hong Kong series and so on): this season's races and winners, whether a horse is on for the sweep (has won every race so far), and how often it has been swept. Seasons follow your Racing season in Settings (or, with Race series keep their own season on, each series runs from its first race to its last). Click a series for every season's winners side by side (a horse that won more than one is highlighted; the sweep winner's row is green) and a points table for any season (5–3–1 for the first three in each race).

Qualifying. Racing → Qualifying lists races you have to earn a place in (the Kentucky Derby by points; the Breeders' Cup, Caulfield Cup and others by finishing in the places in certain races), with how many horses are in so far and how many are yours. Click one for the standings this time round and every race that leads to it, with its points or places and next date.

  • Meetings and Upcoming meetings — every race day. On a meeting, click ▸ next to a runner to open its form: stats for these conditions, jockey and trainer records, and its last starts.
  • Race results — the full result, prize money and sectionals for every runner (with the fastest of each section and top speeds).
  • All races / Group 1 results / Upcoming Group 1s — find any race; filter by type and date.
  • Racecourses — each course has tabs: Overview (tracks, people, tickets, meetings, feature races, and a business summary for the last 12 months with a monthly profit chart), Upcoming races (with entries), Results (runners, winner, jockey, stable and time), Track records (click a distance to see every earlier holder), Sectional records, Trials (every timing trial run there: the sessions, the fastest trial time at each track and distance, and every timed run with its horse, track, distance, time, average speed, place and gap to the fastest; filter by session, track, distance or name) and Finances: the last 12 months against the 12 before, profit margin, income per meeting against a typical racecourse and rank among all racecourses; Income and expenses in detail for the last 12 months or any year the game still itemises: each kind of income and expense with its share and amount per meeting, and the detail behind it (race days and the take per race day for tickets and food, races for media rights and betting commission, each sponsor and its event bonuses, entry and time trial fees, prize money by class of race), with totals and the profit (operating costs are one monthly sum in the save, so they aren't split); month-by-month and year-by-year charts of income, expenses and profit, and income by type; each meeting's runners, purses, betting commission and prize money; and prices and budgets against the average racecourse. Point at a chart to see every figure for that month or year. Years the game only keeps a yearly total for are marked and not split by type.
  • Racecourses a stable owns — a stable that owns any gets a Racecourses tab: all its racecourses' income, expenses and profit month by month, the same Income and expenses in detail panel for all of them together (above the list of racecourses), income and profit by racecourse, and each one's meetings, margin and rank among all racecourses over the last 12 months.

6Stables

Facilities and farm sponsors. A stable's Overview lists what it has built (point at one for what it does), with build cost and daily running costs, and its farm sponsors. A racecourse's page lists its sponsors.

Pick one of your stables from the drop-down in the side menu, or use the ◀ ▶ bar on a stable page to step through every stable you manage, own or share in. Stables you manage come first, marked Manager (or Owner & manager). Each stable page has four tabs:

TabWhat's on it
OverviewCash, net worth, horses, staff, all-time race record, shareholders and recent results.
FinancialsIncome and expenses year by year (▲▼ change on the year before), both broken down by category; Month by month: each month's income, expenses and net for the year you pick, with ▸ for that month's categories; and the payment detail, where Expenses · Income switches between every payment out and every payment in, grouped by category and type, with a filter box. Under Income → Breeding fees, ▸ on the type opens it by horse: each of your stallions with its covers, total, average fee and share, so you can compare what each horse earns at stud (▸ on a horse lists its covers; Each payment shows the plain list). Pick any year and Whole year or a single month; years before the game's payment log starts (it keeps only a yearly total of older payments) show the breakdown by category from the monthly figures. Net worth, cash and income charts are here too.
Horse financesEvery horse the stable has had, now and in the past, with what it earned and cost while it was there, including what was paid to buy it (at auction or privately, or by one of the stable's group stables before it was passed on) and what it sold for. Click ▸ on a horse for its breakdown and year-by-year figures.
AwardsEvery award tied to the stable: its own awards, the season awards and Group/Listed race wins of its horses while they were there, and its staff's awards. Filter by kind, wins only, year, or search by name.

Ownership groups. When a stable belongs to a group, Financials and Horse finances have a This stable · Whole group switch. A group is every stable a person owns outright (all its shares) plus the stables those hold a majority of, or, for stables nobody owns outright, a parent stable and the stables it holds a majority of. The bar lists the group's stables and who holds each. Whole group adds the stables' monthly figures together (money moved between them shows as income in one and spending in another, so the net is right), leaves payments between them out of the payment detail, and adds up each horse's money across the group's stables (transfers between them left out). A person's page has Stables they own with Group financials and Group horse finances buttons.

Every race (top right of a stable) lists every run the stable has had, with filters and Export CSV.

Stable table (the Stable table tab under Stables) has every stable's figures in one wide table. Click any column heading to sort by it; the # column then shows each stable's rank in that column (the best is #1 whichever way you sort, and equal figures share a rank).

Rankings (the Rankings tab under Stables) ranks every open stable, like the game's own league tables, with each stable's owner and country flag. Your stables are highlighted, and Your stables shows just yours with their rank. Pick a table:

Auctions

Auctions in the top menu lists every sale, Upcoming or Past: its auction house, who it's for (type, sex, breed and ages), how many horses, entry fee and commission, and for past sales how many sold, the total and the top price. Click a sale for the horses entered (starting price, reserve, buyout and auto-bids) or, once held, what each sold for and to whom. Auction houses lists every house with its owner, prestige, commission, horses sold and total sales; each has its own page with how it's run, its upgrades, sales each year and its best prices, and a Financials tab: income, expenses and profit for the last 12 months, commission, dividends to its owner, where the money comes from and goes, and month-by-month and year-by-year charts and tables.

A stable that owns auction houses or has sold or bought at auction has an Auctions tab (the houses it owns, its horses entered in sales coming up, and what it has sold and bought), and one that has offered shares has a Share offerings tab (each offering, who could buy in and what they did, and investors' offers).

7People & awards

  • Jockey season — a tab on every jockey (and Your season on Home): seasons start on the day you choose in Settings → Racing season (1 August to begin with; 1 January for calendar years). rides, wins, strike rate, placings, prize money and Group/Listed wins against the same point last season, then strike rate by course, distance and track, their best partnerships with trainers, horses and stables, month by month, the rides they're booked for and their ride offers.
  • Languages and syndicate shares — a person's page shows the languages they speak (the line under each shows how well) and any syndicate shares they hold; People has a language filter and column.
  • People overview — click People at the top for an overview: one section each for jockeys, trainers and managers (the top 8 working now, ranked by wins), with each person's stable, races, wins, prize money, latest race and their Group wins (G1/G2/G3) and Listed wins counted separately and together. Beside them, small Latest awards and Latest news panels; Show more opens each one. Use the year picker at the top to see a single season (or All time), and switch Working now to Everyone (incl. retired) to include people no longer working. Show all on a table lists every jockey, trainer or manager, 25 per page; Top 8 only goes back. All people is still in the side menu. Who's in each table comes from the race results: races they rode, races they trained (as trainer or head trainer, counted once), and every race a stable ran while they were one of its managers. The game writes only one manager on each race, so the viewer gives a stable's race to each manager it had that day: co-managers share the same wins. The line under a name is just their job now.
  • People — jockeys, trainers, managers and staff. A person's Overview has a section for each role, As a jockey · As a trainer · As a manager: their races, wins, prize money, Group wins (G1/G2/G3) and Listed wins counted separately and together (as a manager: every race their stable ran while they managed it, shared with any co-manager), their latest races (Show all for more) and their Group & Listed wins (switch between All, Group and Listed). Small Latest awards and Latest news panels sit beside them; skills, personality, family, jobs and traits are on the page too. Its Awards tab lists their own awards, the horse and concept awards (Horse of the Year, champion awards, Triple Crowns and the like) of horses they rode, trained, managed or looked after, the stable awards (Stable of the Year, the Thravang Award, Breeder of the Year) of stables they owned or managed, and every Group/Listed race win in those roles, with the role and horse on each and a filter for each role. A manager shares in every horse award and race win while they managed the horse's stable, since the game names only one manager on each. These awards count in family and dynasty award totals too.
  • Family tree — a person's Family tree tab shows their ancestors up to 8 generations back (four as a chart, all eight as a fold-out list) and every relative the save links to them: spouses, parents, brothers and sisters, children, aunts and uncles, nieces and nephews, and cousins of any degree (e.g. second cousin once removed). Switch between Close family · + Aunts, uncles & cousins · Everyone. The game links parents and children born since your career began, so trees grow as generations pass.
  • Tree chart — the Tree chart tab draws the family as a proper tree: ancestors above (each couple side by side, joined by a line, with their parents above them), the person in the middle with brothers and sisters beside them and partners next to them (former partners on the left, dashed line = divorced), and children and grandchildren below. Choose how many generations up (up to 8) and down, use − Fit + to zoom, drag to move around, and click any name to put them in the centre.
  • Lifespans — the Lifespans tab puts the person and their ancestors on one time line: a bar for each life, the darker part their racing career (point at it for the job and stable), with dots for season awards, their first win and first Group 1, marriages and children. Pick how far back to go, and add brothers and sisters or children. Underneath: average age at a first child, youngest first win, longest career, and the wins, Group 1s and awards between them.
  • Dynasty — the <surname> dynasty tab shows the family that shares their last name, in three views. Overview: the family's crest, founders, head of the family (the eldest living member of the earliest generation), totals (jockey and trainer wins, Group 1s, awards, prize money, stables; a person's prize money is the race money of every race they rode, trained or managed, each race counted once), its most decorated members, family stables and where else the family works, each generation, and every member in a table. Family tree: a drawn tree from the founders down, partners beside each member (♥; dashed when divorced), with buttons to highlight jockeys, trainers, award and Group 1 winners or who's working now, zoom and drag, an Outline list for very big families, and a summary of each of the founders' children's lines. Chronicle: the family's story decade by decade (births, marriages, deaths, stables founded, first wins, first Group 1s and awards) with a chart of living members, wins per decade and milestones.
  • Jockey stats (People side menu) — everyone's jockey, trainer and stable numbers side by side: rides, wins, strike rate and prize money as a jockey and as a trainer, plus the stable they work at now, its wins and prize money, and what they've earned as a manager. Switch between Jockeys · Trainers · Stable managers · Everyone and click any heading to sort.
  • Awards — season award winners year by year (Horse of the Year, age and distance divisions, breeding, people, stables, Hall of Fame), or Most awards for the all-time list.

Lifestyle assets (People → Lifestyle) lists the houses, yachts, cars, watches, jewellery and other things people own, with what they paid, the price now, upkeep, where it is and whether it's their main home or for sale. Catalogue shows everything there is to buy and how many of each are owned.

8Tables & charts

Tables

  • Sort: click any column heading (click again to reverse). A faint ↕ shows when you point at one. With the keyboard, Tab to a heading and press Enter.
  • Filters: every list has the same filter bar above it, in the same order: what the table lists (for example Sires · Dams or Jockeys · Trainers), a search box, the status (Alive · Deceased · All for horses and people, Active · Closed · All for stables), dropdowns (Any … or All years means no filter), then from–to ranges. When any filter is set, ✕ Clear filters at the end puts them all back.
  • Search this table: bigger tables have a search box next to their CSV button. Esc clears it.
  • CSV: downloads the table for Excel. On list pages, Export CSV at the top downloads every matching row, not just the page.
  • Rows per page: change it under a list (up to 5,000), or set a default in Settings.

Charts

  • Point at a chart for exact values on that date.
  • Linear / Log switches the scale; Log stops one huge value squashing the rest. Money charts start on Log only when a few values dwarf the rest.
  • Smooth (charts with lots of points) averages each point with its neighbours so the trend shows through month-to-month swings; click again for the actual values.
  • Time range buttons (All, 10Y … 1M; ranges too short to show a trend are left out), ⤢ to open the chart large, PNG for a picture, CSV for the numbers.
  • Click a name in the legend to hide that line; double-click it to show only that line.

Numbers, dates & units

The same choices as the game's own display settings: currency, number format (1.2M, 1,2M, 1,234 or 1.234), where the currency symbol goes, decimal places for shortened amounts, odds (decimal, fractional, American or percentage), fractions (1 7/8 or 1⅞), date format and separator, relative dates (days, weeks or auto), 24- or 12-hour time, metric or imperial distances (miles, furlongs and yards; furlongs; or yards), horse height (metres, centimetres, hands, or feet and inches), how far runners finished behind the winner (lengths, distance or seconds), weight (kg, lbs or stone) and temperature (°C, °F, K or °Ra).

Follow the game's settings (on to begin with) reads them from the game's settings.json, which sits a level or two above the Saves folder of the save the viewer follows, so the viewer looks the way the game does; switch it off to choose your own. Money in the save is kept in US dollars: another currency is converted at the Exchange rate shown, which starts at a typical market rate. The game converts with rates of its own that aren't in the save, so to match it exactly, compare one amount in the game and set the rate. Margins in lengths are worked out from the time behind the winner (about 2.4 m to a length).

The other tabs are All tables, Shortcuts (see Getting around) and Tags.

10Updating the viewer

From GitHub (easiest)

New versions are published on GitHub. When one is out, the viewer asks when it opens and shows what's new: click Install now and it downloads, installs and restarts by itself. Remind me later asks again next time (a bar at the top stays until then); Skip this version stops asking about that one.

The Update app button at the top, beside Update data, checks for a new version whenever you click it. When one is out it turns green and shows the version number: click it to install.

Settings → Versions & changes → New versions shows whether you're up to date and has Check now. All versions lists every published version with its changes: Go back to this installs an earlier one if you don't like a new version, and you can update again from the same list whenever you like.

Untick Check for updates automatically there if you'd rather the viewer never looks for new versions by itself; Check now still works whenever you press it.

Anyone can download the full viewer from github.com/HRMViewer/hrm-viewer/releases.

From a file

  1. Updates also come as HRM-Viewer-update-<version>.zip. Don't unzip it.
  2. Go to Settings and click Install an update, choose the file and click Install.
  3. The viewer restarts on the new version by itself.

Updates never touch your stored data or settings. The previous version is kept, and Versions & changes can put it back. A full download (HRM-Viewer-<version>-full.zip) is a complete fresh copy; to keep your data, copy your old data folder into it.

11Good to know

  • Your data stays on your computer in the data folder. Nothing is uploaded anywhere.
  • Sectional times are only kept by the game for Group races and for roughly the last few months of other races, so some racecourses have track records but no sectional records.
  • Live data: the game only writes to database.db when you save, so the viewer shows your last save.
  • All tables (Settings → All tables) shows every table in the save exactly as stored; type under a column and press Enter to filter (e.g. >100, !null).
  • If the window opens in your browser instead, Windows is missing the Microsoft Edge WebView2 Runtime; the viewer tells you where to get it.
